# PROJECT 1

Демонстрационная витрина кроссовок для ORILLON. Интерфейс на английском, цены в евро. Каталог использует локальные данные, а корзина хранится в браузере. Демо-оформление показывает итоговую сумму и подтверждение.

## Запуск

Требуются Node.js 22.18+ или 24 и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [http://127.0.0.1:3000/](http://127.0.0.1:3000/). Для статической публикации используйте содержимое `out/` после `pnpm build`. Развёртывайте экспорт в корне сайта.

```sh
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

## Как устроена витрина

- На первом экране Three.js загружает локальный Air Jordan 1 от makoto (CC BY 4.0). Исходная геометрия уточнена до 840 832 треугольников, UV сохранены. Карты цвета и нормалей увеличены до 4096 × 4096, резкость и микрорельеф доработаны. Двойной клик или двойное касание отводит второй кроссовок и раскрывает первый в послойном ракурсе. Разборка показывает пять слоёв. Язычок, шнурки и люверсы остаются на верхе, протектор движется вместе с подошвой. Повторное действие собирает пару обратно. Второй кроссовок плавно отъезжает в глубину и возвращается после сборки слоёв. Кнопка экспорта сохраняет текущий ракурс в PNG 3840 × 2160. Прокрутка меняет ракурс модели. При разборке общий ракурс добавляет разворот на 15°. Перетаскивание и кнопки управляют независимыми ракурсами пары и разборки. При reduced motion прокрутка сохраняет исходную позу. При отсутствии WebGL 2 виден неподвижный рендер модели.
- 3D Studio загружает отдельный локальный GLB по запросу. Модель можно вращать мышью, пальцем и кнопками, приближать и переключать её три исходных материала. При отсутствии WebGL 2 доступен постер.
- Каталог из 20 моделей доступен на странице /collection/. Страницы товаров генерируются статически из `lib/products.ts`. `lib/store.ts` отвечает за составные фильтры, валидацию сохранённых покупок, количество и сумму.
- Все 24 расцветки используют студийные профили с единым боковым ракурсом и освещением. Кнопка увеличения загружает отдельный файл 3840 × 2160, улучшенный на основе подготовленных товарных изображений. Источники и лицензии перечислены на странице [Asset credits](http://127.0.0.1:3000/credits/).
